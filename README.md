# React Native Activities

This repository contains my React Native activities.

## Activities

### Activity 5: Fetching External Data
A simple React Native application that fetches and displays data from a public REST API using `fetch()`, `useEffect`, and `useState`.

### Activity 6: Multi-Tab Application with Shared State
A React Native application with Home and Settings tabs that uses React Context API to share the theme state between screens.

### Activity 7: Persistent Notes or To-Do App
A simple To-Do application that uses AsyncStorage to save tasks locally and supports Create, Read, Update, and Delete (CRUD) operations.

## Technologies Used
- React Native
- JavaScript
- Expo
- React Hooks
- React Context API
- AsyncStorage
- React Navigation
